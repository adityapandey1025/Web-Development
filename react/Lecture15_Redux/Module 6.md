# Redux Module 6: Dispatch + Reducer vs Reducers 🍳

## Goal

Today we will learn:

- What is dispatch()?
    
- Why do we need dispatch?
    
- What happens after dispatch?
    
- Difference between reducers and reducer.
    

---

# Recap

Current Todo Slice:

```js
const todoSlice=createSlice({

    name:"todo",

    initialState:[],

    reducers:{

        addTodo(){},

        deleteTodo(){},

        editTodo(){},

        toggleTodo(){}

    }

})
```

Question:

How will Component tell Redux to update state?

Answer:

```text
dispatch()
```

---

# dispatch()

Definition:

dispatch() sends an Action to Redux.

Simple Hinglish:

```text
Redux bhai,

ye action process karo.
```

# addTodo Example

```js
addTodo(state,action){

    state.push(action.payload);

}
```

Current State:

```js
[
{
id:1,
text:"React"
}
]
```

Payload:

```js
{
id:2,
text:"Redux"
}
```

Result:

```js
[
{
id:1,
text:"React"
},
{
id:2,
text:"Redux"
}
]
```

# deleteTodo Example

```js
deleteTodo(state,action){

    return state.filter(todo=>

        todo.id!==action.payload

    );

}
```

Payload:

```js
5
```

Delete Todo with id=5.

# reducers vs reducer

This is the most confusing part for beginners.

---

# reducers (Plural)

Inside Slice:

```js
reducers:{

addTodo(){},

deleteTodo(){},

editTodo(){},

toggleTodo(){}

}
```

Question:

What are these?

Answer:

```text
Functions written by us.
```

Need many operations.

So:

```text
reducers
```

Plural.

---

# Redux Toolkit Magic

Toolkit automatically creates:

```text
Actions

+

One Combined Reducer
```

Visual:

```text
reducers

↓

addTodo

deleteTodo

editTodo

toggleTodo

↓

ONE reducer
```

---

# reducer (Singular)

Redux Toolkit creates:

```js
todoSlice.reducer
```

Question:

Why singular?

Store needs only ONE reducer per Slice.

Store does NOT need:

```text
addTodo

deleteTodo

editTodo
```

Store needs:

```text
One Combined Reducer
```

---

# Actions

Toolkit also creates:

```js
todoSlice.actions
```

Contains:

```text
addTodo

deleteTodo

editTodo

toggleTodo
```

Need Component?

Import Actions.

```js
export const {

addTodo,

deleteTodo,

editTodo,

toggleTodo

}=todoSlice.actions;
```

---

# Store Needs

Need Slice logic.

```js
export default todoSlice.reducer;
```

Store:

```js
configureStore({

reducer:{

todo:todoSlice.reducer

}

})
```
