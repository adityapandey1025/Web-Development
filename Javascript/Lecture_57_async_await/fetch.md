# 🔥 **What is fetch()?**

**fetch() = JavaScript ka built-in function jo server se data lane (API call) ke kaam aata hai.**

Fetch → HTTP request bhejta hai  
Aur → Promise return karta hai

Matlab:

- Server se baat karo
    
- Data lao
    
- JSON parse karo
    
- Error handle karo
    

Sab kuch fetch() karta hai.

---

# ⭐ Fetch = "network request"

Ye browser ke andar by default hota hai.  
Iska use hum GET, POST, PUT, DELETE sab me kar sakte hain.

---

# 🔎 **Basic Syntax**

```js
fetch(url)
```

Ye ek **Promise** return karta hai.
