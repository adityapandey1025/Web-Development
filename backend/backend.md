# Backend

## What is Backend?

Backend is the server-side part of an application that handles business logic, authentication, database operations, security, and API communication.

---

## Client-Server Architecture

Client (React)
        ↓
HTTP Request
        ↓
Backend (Node + Express)
        ↓
Database (MongoDB)
        ↓
HTTP Response
        ↓
Client Updates UI

---

## Responsibilities of Backend

- Authentication
- Authorization
- Business Logic
- Database Operations
- Security
- File Uploads
- API Creation

---

## Why Node.js?

Node.js allows JavaScript to run outside the browser using the V8 JavaScript Engine.

Capabilities:
- Create web servers
- Read/write files
- Connect to databases
- Build REST APIs
- Handle real-time communication

---

## Browser vs Node

Browser:
- DOM
- Window
- Document
- UI Rendering

Node:
- File System
- HTTP Server
- Database
- Operating System Access
